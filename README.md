# ETL with Pure Python

## Descripción

Repositorio dedicado al desarrollo y resolución de tareas relacionadas con procesos **ETL (Extract, Transform, Load)** utilizando Python nativo, sin librerías externas.

El objetivo es comprender y aplicar la lógica de procesamiento de datos desde cero, trabajando las distintas etapas de un proceso ETL.

## Objetivos

- **Extract:** extracción y lectura de datos.
- **Transform:** limpieza, manipulación y transformación de datos.
- **Load:** organización y almacenamiento de los resultados.
- Aplicar fundamentos de Python a problemas reales de procesamiento de datos.

## Tecnologías

- Python 3
- Python Standard Library
- Git & GitHub

## Enfoque

Resolución de ejercicios prácticos mediante código Python nativo, aplicando estructuras de datos, funciones, bucles, condicionales y operaciones de manipulación de datos.

**Project focus:** Python · ETL · Data Processing · Data Analytics
